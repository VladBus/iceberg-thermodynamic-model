# Documentation Archive

`docs/archive/` holds superseded plans, local workflow records, and provenance
artifacts that are no longer part of current model guidance.

## Contents

- `PROJECT_ROADMAP.md` — historical roadmap snapshot; not a current work plan.
- `provenance_archive/` — superseded acquisition manifests and records retained
  for traceability.

Completed scientific stage reports are **not** stored here. They belong under
`docs/wiki/stages/<stage>/` with their evidence and a directory index. Current
physics and mathematical descriptions belong in `docs/model/`; bibliography,
scientific premises, and data-source contracts belong in `docs/references/`.

Do not delete archived material simply because it is old. Remove it only after
confirming it contains no unique provenance or scientific result and no current
document references it.
