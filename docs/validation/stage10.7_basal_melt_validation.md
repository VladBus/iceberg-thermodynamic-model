## 1. Проверяемая формулировка (production, Stage 10.6)

Цепочка базального таяния, реализованная в `src/iceberg_types.f90:421-448`
(`ocean_heat_transfer_coeff`) и `src/iceberg_thermodynamics.f90`
(`compute_basal_melt`):

```
U_rel(z)  = sqrt((u_water − u_ice)² + (v_water − v_ice)²)   [m/s]
Re        = U_rel · L_char / ν                              [–]
Nu_lam    = 0.664 · Re^0.5 · Pr^(1/3)       (Re <  5e5)
Nu_turb   = 0.037 · Re^0.8 · Pr^(1/3)       (Re ≥  5e5)
γ_T       = Nu · k / L_char                                [W/(m²·K)]
Tf(S,D)   = (A0 + A1·√S − A2·S)·S + BP·P    (EOS-80, P = ρ_w·g·D/1e4)
ΔT        = max(T(D) − Tf(D), 0)
m_basal   = γ_T · ΔT / (ρ_ice · L_f)                       [m/s]
```

Параметры (production, `iceberg_types.f90`):

| Параметр | Значение |
|---|---|
| Pr (Прандтль, морская вода @ ~0°C) | 13.8 |
| ν кинематическая вязкость | 1.82e-6 m²/s |
| k теплопроводность | 0.56 W/(m·K) |
| Re_crit | 5e5 |
| ρ_ice / ρ_w | 910 / 1028 kg/m³ |
| L_f | 3.34e5 J/kg |
| НЕ используется | CD_ICE_OCEAN=2.2e-3, STANTON_THERMAL=0.011, STANTON_HALINE=3.1e-4 (трехкомпонентная формулировка не реализована) |

### 2.1. Ключевой вывод литературного аудита

- Выбор **flat-plate термодинамической аналогии** для базального таяния таблитчатого
  айсберга научно обоснован: для таблитчатой геометрии и доминирующего вынужденного
  течения это стандартное приближение (FitzMaurice & Stern 2018; Martin & Adcroft 2010).
- **Открытый вопрос:** трёхкомпонентное замыкание (Γ_T/Γ_S) даёт m ∝ U (линейно),
  тогда как flat-plate даёт m ∝ U^0.8·L^−0.2·ΔT. Оба подхода укладываются в
  наблюдаемый диапазон; различие в скейлинге по U принципиальное и должно быть
  накоплено статистикой наблюдений (см. §6).
- Константы W&C (0.664, 0.037) и exponents проверены по первоисточникам — совпадают.

## 3. Математический аудит

1. **Размерность:** γ_T = Nu·k/L_char → [W/(m²·K)] ✓; m = γ_T·ΔT/(ρ_ice·L_f) → [kg/(m³)·K·J·/(...)]:
   γ_T [W/(m²·K)] · ΔT [K] = [W/m²] = [J/(s·m²)]; деление на ρ_ice·L_f [J/m³] → [m/s] ✓.
2. **Exponents (исправлены в `40d4a3b`):** γ_T ∝ L^−0.5 (laminar) и L^−0.2 (turbulent).
   Отрицательные степени длины подтверждены пересчётом γ_T = Nu·k/L при Nu ∝ Re^0.5/0.8:
   laminar: L^0.5·L^−1 = L^−0.5; turbulent: L^0.8·L^−1 = L^−0.2 ✓.
3. **Скейлинг скорости:** laminar m ∝ U^0.5; turbulent m ∝ U^0.8 ✓ (проверено аналитически и тестом E).
4. **Линейность по ΔT:** m ∝ max(ΔT,0); холодная вода (ΔT≤0) → m=0 (без отрицательного таяния) ✓.
5. **Скачок на Re_crit:** Nu_lam(5e5)≈1124 vs Nu_turb(5e5)≈3214 → разрыв γ_T ≈ **2.90×**.
   Внутреннее свойство кусочной корреляции; используется `.ge.` (Re=5e5 точно → турбулентный).
   Для реалистичных айсбергов (L=100–1000 m, U=0.01–0.5 m/s → Re ≈ 5.5e5–2.7e8)
   режим фактически всегда **турбулентный**; ламинарный — только для малых айсбергов
   при слабом течении (Re < 5e5).
6. **Условие U_rel=0:** γ_T=0 → m=0 (охранник в `ocean_heat_transfer_coeff`). Это
   **естественная конвекция не учтена** (см. §5).

### 4.1. Кросс-проверка с трёхкомпонентным замыканием (порядок величины)

Для канонического случая (U=0.1 m/s, L=100 m, ΔT=3.93 K):

- **Flat-plate (production):** γ_T = 122.5 W/(m²·K), m ≈ 0.137 m/day.
- **Трёхкомпонентный оценка (in-repo commented константы):**
  u* = √(Cd)·U = √(2.2e-3)·0.1 = 4.69e-3 m/s;
  γ_T^(3eq) = ρ_w·c_p_w·St·u* = 1028·4186.8·0.011·4.69e-3 ≈ **222 W/(m²·K)**;
  m ≈ 0.248 m/day. Отношение 0.55 → фактор ≈ **1.8**, согласие порядка величины.

*Примечание о конвенции:* значение Γ_T=0.011 в коде используется как
безразмерное число Стентона (γ_T ∝ St·u*). Чувствительность к конвенции
(мультипликативной или делительной) документируется; требуется независимая
верификация по первоисточнику (ограничение сети, см. §8).

## 5. Интерпретация и ограничения

Ограничения formulation (не «баги», а явные допущения модели):

1. **Естественная конвекция не представлена:** при U_rel → 0 модель даёт m=0,
   тогда как реальный айсберг тает за счёт melt-plume конвекции. Наибольшая
   значимость при слабых течениях (U < 0.02 m/s).
2. **L_char = state%L всегда вдоль X.** Нет прогностической ориентации; корректно
   только при U_rel вдоль X. Для бокового таяния W&C предписывают L_char = D (draft) —
   текущий вызов для бокового таяния использует отдельную legacy-ветку (C_LATERAL).
3. **Однородная температура айсберга:** без внутренней температурной диффузии
   и без прогностического T_внутр; ΔT представляет последний океанский уровень у черновика.
4. **Кусочная корреляция Re_crit = 5e5** с разрывом γ_T ≈ 2.9×.
5. **Постоянные коэффициенты 0.664/0.037** — для гидродинамически гладкой пластины;
   шероховатая поверхность айсберга даёт бо́льшие коэффициенты (не оценивается).
6. **Трёхкомпонентное замыкание (Γ_T/Γ_S) не реализовано** — плоская пластина не
   моделирует сопряжённую кинематику таяния (salt-buoyancy feedback).

Классификация остаётся **B**: формулировка согласуется с литературой и наблюдаемым
диапазоном, но требует калибровки/сопряжённого замыкания (Stage 9.4/10.x).

### 6.1. Будущая верификация: NEMO / AARI-модель

- **NEMO + SIMIP/iceberg coupling:** плоско-пластинчатое замыкание сопоставимо с
  замыканиями в NEMO iceberg module (c_vel/ocean_vel, thermal forcing три-уровневые).
  План: спектр ρ-ΔT-U режимов прогнать в standalone, сравнить m(профиль) с NEMO
  "Icebergs" package (Martin & Adcroft 2010 инстанцирован в NEMO).
- **AARI-модель (базовая, Дмитриев-Нестеров):** историческое замыкание
  (∝ ΔT, эмпирические коэффициенты) — flat-plate-аналог должен воспроизводить
  порядок величины таяния в контрольных расчётах Q1-2020 (TEST_11 baseline).
- Пошаговая процедура, метрики и пороги — предмет Stage 10.8/10.9, фиксируются в плане.

## 7. Python-слой валидации (минимальный интерфейс)

Для последующей наблюдательной статистики (Stage 10.8+) в `python/analysis/`
рекомендуется минимальный независимый калькулятор:

```python
def basal_melt(u_rel_m_s, l_char_m, dT_K):
    re = u_rel_m_s * l_char_m / 1.82e-6
    nu = (0.037 * re**0.8 if re >= 5e5 else 0.664 * re**0.5) * 13.8**(1/3)
    gamma = nu * 0.56 / l_char_m
    return gamma * max(dT_K, 0.0) / (910.0 * 3.34e5)   # m/s
```

Порог сверки с production: относительная ошибка < 1e-3 на I-кейсе (float64 vs float32).
**Не в scope 10.7;** реализация закреплена за Stage 10.8.
