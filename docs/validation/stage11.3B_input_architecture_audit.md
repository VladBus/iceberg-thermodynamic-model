## 1. Input data path audit

### 1.1 ERA5 atmosphere (`netcdf_input` + `wind_forcing.era5_wind`)

- Variables: u10, v10, t2m, d2m, msl, tcc, sf (snowfall). Files:
  `data/input/processed/era5/2020/{2020_01 fullcoverage, 2020_04/07/10 monthly,
  2020_Q1, 2020_02/03}_merged.nc` (pipelines: `download_era5.py`,
  `merge_snowfall.py`; stats: `check_era5.py`, `stage7_6c2_forcing_stats.py`,
  `model_coverage.py`).
- Spatial: bilinear (`era5_bilinear2d`), lon wrapped ±180°, lat NOT wrapped —
  out-of-range lat returns ok=false. Temporal: `era5_find_time_index` daily
  slice + per-`iii` linear wind interpolation (`tx→tx1`, `dpx→dpx1`, …).
- Coverage: monthly files start at 65.0°N (Jan fullcoverage at 63.0°N); 55
  model cells (lat<65°) fall back to nearest edge (D32; previously zero-init
  → Day-1 zombie, D24–D31). Only the u10 `ok` is checked (`cycle` skips cell).
- Units/conversions: u10/v10 m/s → ×100 cm/s; msl Pa → ×0.01 hPa (`patm`,
  `p1`); t2m K → −273.15 °C (`tatm`); humid = e_sat(d2m)/e_sat(t2m) (Tetens);
  snowfall `sf` m/s water equivalent (/43200 s accumulation convention);
  wind stress quadratic law (Cd0=1.1, Cd1=0.04) with spd>1e-6 guard.
- Missing policy: out-of-range → nearest edge (D32); land masked post-hoc
  (`wind=1.70141e38` where `ht≈8888`). No NaN fill anywhere in chain.

### 1.2 EN4 ocean initial conditions (`initial_ocean_reader` + `build_initial_ts.py`)

- Product: `data/input/processed/ocean/initial_ts_YYYY-MM-01.nc` from
  `data/input/raw/ocean/EN.4.2.2.f.analysis.g10.*.nc` (pipelines:
  `download_initial_ts.py`, `build_initial_ts.py`, `check_initial_ts.py`).
- Reader: T [°C], S [mass fraction], land/bottom = 0.0 (never NaN),
  `wet_mask`; axis-order independent; `ICEBERG_OCEAN_INIT_FILE` override;
  fallback to synthetic `init_ocean()` on failure.
- Builder fixes (D21/D22): metre-unit `d_en4` + canonical `Z_M`; vertical
  regrid model-z ↔ EN4-z. Known residual: small finite negative-ro excursions
  (D23 cause-REJECTED, D33 baselines confirm finite).
- Coverage: full model wet grid (143422 cells); monthly (Jan/Apr/Jul/Oct).

### 1.3 Sea-ice initialization (`build_real_grid_inputs.py`)

- Raw: OSI-SAF CDR SIC (`osisaf/ice_conc_…cdr-v3p1…nc`) + C3S CS2SMOS SIT
  (`c3s_sit/…cs3smos-v1p1…nc`, 2020-01-01). Processed:
  `sic_model.nc`, `sit_model.nc`, `category_concentrations_20200101.nc`.
- Model input: `1_1..1_5.ice` (area fractions, text, symlinked to CWD) +
  `wice1` = hst·an1 with hst = (0.20, 0.40, 0.95, 1.60, 2.50 m); snow init 0.
- Gap: single January state reused for ALL months (April freezing regime
  difference observed in D30/D31 partly stems from stale ice init).

### 1.4 Grid & bathymetry (`grid_coupling`, `initial_ocean_reader`)

- `KOORD.DAT`: FI/DL (lat/lon), list-directed, (133,105); FATAL STOP if
  missing. `hhh.bar`: land mask (8888.0) + depth index KT1 (8=land,
  3..600 = depth units); synthetic-basin fallback if missing. Generated by

- Grid: IS=132, JS=104, KS=18 (+1 halo → 133/105/19); DX=13.89 km

## 3. NetCDF contract design (model-ready, CF-1.10)

- 3.1 `grid.nc`: dims x(133)/y(105)/z(18); vars lon/lat/bathymetry/wet_mask/
  land_mask/T_mask/U_mask/V_mask/vertical_levels/thickness; attrs CRS
  (Polar Stereographic), provenance. Replaces KOORD.DAT + hhh.bar (primary).
- 3.2 `forcing_YYYYMMDD.nc`: dims time/y/x; vars u10/v10/t2m/d2m/msl/tcc/
  snowfall (+ future swh/Tp/wave_dir); REQUIREMENT model domain ⊂ forcing
  domain with margin (D32 lesson codified). Replaces raw ERA5 post-merge.
- 3.3 `ocean_initial_YYYYMMDD.nc`: dims z/y/x; temperature (K), salinity
  (kg/kg with documented convention); replaces EN4→builder output format
  (same content, frozen units/metadata).
- 3.4 `ice_initial_YYYYMMDD.nc`: dims category(5)/y/x; SIC/SIT +
  category_fraction/thickness[5] + snow_thickness[5] (monthly, not
  January-only). Replaces `1_*.ice` (+ export path kept during transition).
- 3.5 `tides.nc` (future): dims constituent(4)/y/x; amplitude/phase for
  M2/S2/K1/O1. Replaces GRM2 family when data acquired.
