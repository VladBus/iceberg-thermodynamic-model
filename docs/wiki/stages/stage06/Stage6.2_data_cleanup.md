# Stage 6.2 — Data Cleanup Report

## Scope

Inventory, classification and disposition of all files under `data/` carried
over from Stages 1–5.5b, plus the new run-based layout introduced in Stage 6.2.

Classification legend:

- **KEEP** — required by the model / tests / regression validation
- **ARCHIVE** — valuable but not actively used; moved under `data/archive/`
- **REGENERATABLE** — produced by a script or re-downloadable from CDS
- **DELETE** — stale/temporary/junk, removed permanently
- **UNKNOWN** — not classified (none remaining)

## Post-Cleanup Guarantees

1. All model outputs live under `data/runs/<run_id>/`; `data/output/` is empty.
2. `run_manifest.py` (run-aware) validates each run; `data/runs/.../manifest.json`
   is the single source of truth for analysis file selection.
3. `era5_test.nc` preserved for regression use (`check_era5.py --domain arctic` PASS).
4. Everything in `data/` is Git-ignored (`data/`, `*.nc`, `*.vtk`, `*.dat`).
