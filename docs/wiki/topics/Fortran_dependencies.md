# Fortran dependencies

## Toolchain

- `gfortran`
- `fpm` 0.13.0-alpha
- `netcdf-fortran` (system library, linked as `netcdff`)

`netcdf.mod` is installed under `/usr/include`, outside the fpm tree. Always
pass `-I/usr/include`:

```bash
fpm build --flag "-I/usr/include"
fpm test  --flag "-I/usr/include"
```

## Project dependencies

`fpm.toml` currently declares no external Fortran package dependencies
(`[dependencies]` is empty). The former `stdlib` dependency was removed during
Stage 10.12; do not restore it without a documented need.

`build/` is generated by fpm and is not committed to Git.
